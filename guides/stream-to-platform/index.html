Direct streaming

Stream straight from your phone.

Send Roam directly to Twitch, Kick, a restreaming service, or any other compatible RTMPS or encrypted SRT destination.

1. Get your destination

Open the streaming settings or creator dashboard for your platform or service. Find its server address and your private stream key.

Roam uses one complete URL. If the service gives you the server and key separately, the finished RTMPS destination normally looks like this:

rtmps://server.example/app/your-private-stream-key

Use the exact server format supplied by your service. If it supplies SRT instead, the SRT URL must include a passphrase because Roam blocks unencrypted SRT.

2. Enter it in Roam

  1. Open Settings > Stream.
  2. Paste the complete RTMPS or encrypted SRT URL into Stream URL.
  3. Save it as one of the four destinations if you expect to use it again.
  4. Open Video quality. Start with Data saver and Auto bitrate for a mobile-data test.
  5. Check the microphone meter under Audio.

3. Run the first test

  1. Use a platform test mode, private destination, or unlisted stream if one is available.
  2. Hold Go Live until the ring completes.
  3. Confirm Roam says LIVE, the timer continues, the microphone moves, and the platform receives video.
  4. Watch the NET status while moving between Wi-Fi and mobile data.
  5. Press Stop when finished and confirm the platform has ended the stream.

NET measures Roam's connection to the Stream URL you entered. It does not measure phone signal bars, general internet access, or the path after that destination receives your feed. Tap NET for details.

Troubleshooting

If Roam rejects the URL, check that it starts with rtmps://, rtmpts://, or srt://. Plain rtmp:// and SRT without a passphrase are blocked.

If Roam stays on Connecting, confirm an ordinary website loads, rotate the stream key if it may have been exposed, and compare the server and key with the platform dashboard again.

Keep the complete URL private

The complete destination contains your stream key or SRT passphrase. Do not put it in screenshots, messages, public posts, or diagnostics. Rotate it if it is exposed.

For other app controls, see Using Roam. If something fails, see Support.
