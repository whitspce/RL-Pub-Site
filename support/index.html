Get unstuck.

Run the quick checks first. If something still fails, send a small report with the details needed to reproduce it.

Quick checks

Current test release: 0.10.3. Install the open beta from Google Play.

  • Run one private or unlisted test with Data saver and Auto bitrate on.
  • Under Settings > Stream, enter a complete RTMPS or encrypted SRT URL.
  • Check camera, microphone, notification, and optional location permissions.
  • Do not forward UDP 1234 or TCP 4455. Follow the tested home OBS guide instead.

Follow Phone to platform for a direct stream, or Phone to home OBS for a private phone-to-OBS connection.

Report a problem

Email feedback@roamlive.app to report a problem. Include:

  • Roam version.
  • Phone model and Android version.
  • Streaming protocol and destination type, but no URL or key.
  • What you expected and what happened.
  • Exact steps that make it happen again.
  • Whether it happens on Wi-Fi, mobile data, or both.

Do not post secrets

Never send a stream URL, stream key, SRT passphrase, OBS password, private tailnet details, or a screenshot containing them. Rotate a credential at once if it is exposed.

Export diagnostics

  1. Open Settings > Help & about.
  2. Choose Save diagnostic log.
  3. Open the text file and review it before sharing.
  4. Send it by email only when it is relevant to the report.

The export is designed to remove stream URLs and passwords. It can still include phone details, configured chat channel names, and operational events. Remove anything you do not want to share.

Report a security issue

For security problems, email feedback@roamlive.app with a short description and a safe way to reproduce it. Do not include live credentials.
