Built for the phone

Enough control without a control room.

Chat on screen

Read public Twitch, Kick, and YouTube chat on the phone. It is not drawn into the broadcast.

BRB & Stealth

Keep chat and controls out of sight when the rear camera faces you and the screen faces the public. While live, Stealth blacks out the display and can reduce screen power use and heat.

Overlays

Add text, images, and web overlays. Build a useful layout without turning the phone into a desktop editor.

Field reliability

Auto bitrate, reconnect attempts, local recording, an audio level meter, and thermal safeguards help with real mobile conditions.

Protect your stream key

Treat a stream URL like a password. Use RTMPS or encrypted SRT. Rotate the key or passphrase if it is exposed.

Privacy

No Roam account or developer analytics.

Roam sends media and network requests only where a feature needs them. Streaming platforms, chat services, web overlays, Tailscale, and the website host still handle data when you use those services.
